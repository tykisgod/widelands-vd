# Widelands 简体中文译文风格规范

术语一律以 `glossary.tsv` 为准，本文只管术语之外的事。

## 人称

**一律用「你」，不用「您」。** 现有译文两者混用，甚至出现在同一句里
（`widelands/zh_CN.po` 中「你的一些起始建筑…… 您在这方面处于劣势」）。
Widelands 是单人／小规模多人的建造游戏，「你」更自然，也与绝大多数中文
游戏本地化一致。

## 标点

- 中文文案内用全角标点：，。；：？！「」
- 占位符、英文标识符、数字周围保持半角，两侧不额外加空格
  - 对：`已保存 %s 个文件。`
  - 错：`已保存 %s 个文件 。`
- 句末不留空格。现有译文有大量句尾多余空格，会影响 UI 拼接
- 省略号用 `…`（单个字符），不用 `...`；原文用 `…` 的保持 `…`
- 英文引号 `“ ”` `‘ ’` 在原文中出现时原样保留，不改成中文引号——
  它们常与占位符配合构成 `“%s”` 这类结构

## 长度

- **按钮、菜单项、标签页**：求短。四字以内为佳，尽量不超过六字
- **工具提示、状态行**：一句话说清，不堆砌
- **对话框正文、帮助文本**：完整通顺，不为求短牺牲清晰

中文通常比英文短，一般不会溢出；但固定宽度的按钮仍需留意。

## 语气

- 界面元素用名词或名词短语：`Save Game` → `保存游戏`，不是`保存这个游戏`
- 确认框用疑问句：`Do you really want to…?` → `确定要……吗？`
- 错误提示陈述事实，不甩锅、不道歉：
  - 对：`无法读取存档文件。`
  - 错：`抱歉，很遗憾我们没能读取您的存档文件。`
- 进行中状态用`……中`或`正在……`：`Loading…` → `加载中…`

## 不翻译的内容

见 `keep-english.txt`。原则：

- 技术专名与品牌名（OpenGL、Linux、Windows）
- 单位符号（GB、MB、kB）
- 键盘按键名（Page Up、Ctrl、Shift）——与键帽印字一致便于对照
- 玩家自定义内容（存档名、地图作者名）

## 占位符

- 数量、种类、参数编号必须与原文一致，由 `check_po.py` 强制
- **允许且鼓励按中文语序重排**：原文 `%s costs %d`，译文可写
  `%2$d 元买 %1$s`。校验器按「参数位 → 类型」比对，能正确识别重排
- `%N%` 是「第 N 个参数」，不是字面百分号。字面百分号写 `%%`
- 复数条目只填 `msgstr[0]`（中文 `nplurals=1`）

## 常见陷阱

| 原文 | 易错译法 | 正确 |
|---|---|---|
| weren't built | 尚未建设完成 | 没有建成（根本没建，不是没建完） |
| Fortress | 哨所 | 要塞（哨所是 Sentry 的语义） |
| General（统计菜单） | 将军 | 综合 |
| add-on | 附件／插件 | 附加内容 |
| Desync | 脱同步 | 不同步 |
| Wares | 货物 | 物品（沿用既有一致译法） |
